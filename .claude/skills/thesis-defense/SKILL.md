# Thesis defense preparation

Base every slide, conclusion, diagram, and demonstration on the approved assignment, implemented behavior, and verified experiments. If any are unavailable, identify the gap; do not invent a result, requirement, person, date, or approval.

Trace each assignment task to an implemented or designed artifact, its evidence, and the exact conclusion it supports. Build a clear narrative from problem and goals through architecture, implementation, evaluation method, measured results, limitations, and conclusions. Ensure diagrams reflect actual component boundaries and actual live-capture versus post-meeting API behavior.

For every chart state metric, baseline, dataset, sample count, units, conditions, and uncertainty. Do not turn target thresholds into attained results. Prepare concise, evidence-based answers on why an agent approach is needed, capture permissions and consent, privacy, ASR/LLM choices, latency, baseline, validity, and integration limitations.

Use only authorized demonstration data; prepare a network/API-independent fallback. Confirm presentation length, required artifacts, and formatting with current department guidance rather than assuming a standard.

Reference: [Anthropic Agent Skills and best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview).
