# Thesis research

Work in Ukrainian unless asked otherwise; preserve original names of publications, APIs, and standards. Begin by bounding the research question and date/version scope. Prioritize peer-reviewed primary literature, standards, official platform/API documentation, and library documentation.

For each source, record bibliographic details or stable URL, type, method, data, metrics, result, limitations, and relevance to the assignment. Separate documented API capability from measured product quality and from your own inference. Compare sources using consistent criteria such as latency, accuracy, language coverage, privacy, integration limits, and reproducibility. Synthesize by theme and identify evidence gaps; do not merely paraphrase abstracts.

Never invent citations, DOI values, quotations, pages, or results. If full text is unavailable, state that and limit claims to accessible evidence. For changing web sources, record version or access date.

Useful starting points: [Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview), [Google Meet API](https://developers.google.com/workspace/meet/api/guides/overview), [OpenAI Realtime transcription](https://developers.openai.com/api/docs/guides/realtime-transcription), [Anthropic Messages](https://platform.claude.com/docs/en/api/messages), and [Anthropic tool use](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview).
